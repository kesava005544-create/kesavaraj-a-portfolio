## 🚀 Getting Started

### Option 1 — Open Locally

Just download or clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/your-username/portfolio.git
cd portfolio
# Open index.html in your browser
```

No build tools, no npm install, no frameworks — it works right out of the box.

---

### Option 2 — Deploy with GitHub Pages (Free Hosting)

1. Push your code to a GitHub repository named `portfolio` (or any name)
2. Go to your repo → **Settings** → **Pages**
3. Under **Source**, select `main` branch → `/ (root)`
4. Click **Save**
5. Your site will be live at:
   ```
   https://your-username.github.io/portfolio
   ```

---

### Option 3 — Deploy with Vercel (Recommended)

1. Go to [vercel.com](https://vercel.com) and sign in with GitHub
2. Click **Add New → Project**
3. Import your `portfolio` repository
4. Click **Deploy**
5. Done! You get a free URL like `https://portfolio-username.vercel.app`

## ✏️ Customization Guide

### 1. Update Your Name & Info
Open `index.html` and search for `KESAVARAJ` — replace with your name.

### 2. Replace Your Photo
Swap `Image.png` with your own photo. Keep the same filename, or update the `src` attribute in the `<img>` tag inside the hero section.

### 3. Update Contact Details
Find the **Contact** section and replace:
- `kesava005544@gmail.com` → your email
- `+91 9344335886` → your phone number
- LinkedIn and GitHub `href` links → your actual profile URLs

### 4. Add / Edit Projects
Copy an existing `.project-card` block and update the title, description, and tech tags.

### 5. Change Colors
Edit the CSS variables at the top of the `<style>` block:

```css
:root {
    --accent: #7c3aed;   /* Purple — primary accent */
    --accent2: #06b6d4;  /* Cyan — secondary accent */
    --accent3: #f59e0b;  /* Amber — highlight color */
    --bg: #060610;       /* Page background */
}
```
